# Repository instructions

Read and follow [CLAUDE.md](CLAUDE.md) for this repository's development,
testing, user-facing text, and release rules.

For changelogs, follow its **CHANGELOG entries** section: the baseline is the
latest version already released from `main`. Keep the cumulative differences
from that baseline across dev/beta releases, rather than replacing the list with
only the current task's changes. Use that same list in release and updater notes.
